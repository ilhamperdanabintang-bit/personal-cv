# Website CV — Ilham Perdana Bintang

Website CV pribadi modern minimalis untuk tugas HTML dan CSS.

## File proyek
- `index.html` — struktur dan isi website.
- `style.css` — seluruh styling dalam file CSS eksternal.

## Cara melihat website
1. Simpan kedua file dalam folder yang sama.
2. Buka `index.html` di browser.

## Sebelum dipublikasikan
- Ganti email contoh `emailkamu@example.com` dengan email milikmu.
- Ganti nomor telepon contoh dengan nomor yang ingin ditampilkan (atau hapus bagian telepon).
- Ganti link GitHub dan LinkedIn dengan profil asli.
- Sesuaikan pendidikan, pengalaman, dan keterampilan dengan data sebenarnya.
- Ganti placeholder inisial `IPB` dengan foto pribadi jika ingin.

## Cara upload ke GitHub Pages
1. Masuk ke https://github.com/ dan buat repository baru dengan nama, misalnya `cv-ilham`.
2. Pilih **Public**, lalu buat repository.
3. Upload `index.html` dan `style.css` ke root repository (bagian utama, bukan di dalam folder lain).
4. Buka **Settings → Pages** pada repository.
5. Di bagian **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
7. Tunggu proses publikasi selesai. Alamat biasanya `https://USERNAME.github.io/cv-ilham/`.
8. Buka link tersebut dan pastikan tampilannya benar.

## Catatan formulir kontak
Formulir pada contoh ini memakai `mailto:`. Formulir tidak menyimpan atau mengirim pesan melalui server; pengunjung mungkin perlu aplikasi email yang sudah dikonfigurasi. Backend atau layanan formulir diperlukan untuk pengiriman langsung dari website.

## Persyaratan CSS yang ditunjukkan
- External CSS melalui `<link rel="stylesheet" href="style.css">`
- Selector elemen, class, dan ID
- Box model: `margin`, `padding`, `border`
- Tipografi: `font-family`, `font-size`, `line-height`, dan text alignment
- Palet warna yang konsisten
- Layout menggunakan CSS Grid dan Flexbox
- Media queries untuk tampilan ponsel dan tablet
